# Chocolate Shipment Data Visualization and Dashboard

## 1. Project Overview

This project focuses on analyzing and visualizing chocolate shipment data using Microsoft Power BI.

The dataset contains information about shipments, products, sales amount, number of boxes, shipment dates, order status, and geographic locations.

The main purpose of this project is to transform the available data into meaningful and easy-to-understand visualizations through an interactive dashboard.

## 2. Dataset

The dataset contains the following important information:

* Shipment ID
* Sales Person ID
* Product ID
* Geography ID
* Shipment Date
* Sales Amount
* Number of Boxes
* Order Status
* Product Category
* Geographic Location
* Region
* Sales Person
* Team

The dataset was imported from an Excel workbook into Power BI.

## 3. Tools Used

* Microsoft Excel
* Microsoft Power BI Desktop
* Power BI Visualizations
* Power BI Slicers
* Power BI Data Model

## 4. Dashboard Visualizations

The following visualizations were created in the dashboard:

### Bar Chart

**Shipment Distribution by Order Status**

This chart shows the number of shipments under different order statuses.

### Column Chart

**Total Sales Amount by Product Category**

This chart compares the total sales amount for different product categories.

### Line Chart

**Monthly Sales Trend**

This chart shows how the total sales amount changes over time by month.

### Donut Chart

**Shipment Status Distribution**

This chart represents the percentage distribution of shipments based on order status.

### Map

**Sales Distribution by Location**

This map shows the geographic distribution of sales based on location.

### Slicer

**Category Filter**

The category slicer allows users to filter the dashboard based on product category and interact with the visualizations.

## 5. Data Model

The Power BI data model uses three main tables:

* **Shipments** – contains shipment and sales transaction data.
* **Dimension Data** – contains product, category, geographic, salesperson, and related information.
* **Calendar** – contains date, month, year, and weekday information.

Relationships were created between the tables to allow the data to work together correctly in the dashboard.

## 6. Key Findings

The dashboard provides an overall understanding of:

* Shipment distribution by order status
* Sales performance across product categories
* Monthly sales trends
* Percentage distribution of shipment statuses
* Geographic distribution of sales

These visualizations make it easier to understand the dataset and identify patterns in shipment and sales information.
